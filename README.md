## 2.部署

观察上面的链接，确保你已经安装好了ollama和python
接下来，你需要建立一个虚拟环境

```powershell
python -m venv .venv
```

然后进入它

```cmd
.\.venv\Scripts\activate
```

接下来安装依赖

```cmd
pip install -r requirements.txt
```

确保你的ollama已经在后台运行，它会出现在右下角的系统托盘，或者你选择手动启动（新建终端）
你可以访问[这个页面](http://127.0.0.1:11434/)，若观察到`Ollama is running`就已经启动成功

```cmd
ollama serve
```

然后回到你的虚拟环境

```cmd
python main.py
```

然后访问弹出的页面，你的服务已经跑起来了`^_^`

## 3.实现思路

### （1）先来说一下背景吧

这个项目的起因是我想给同学生成一篇长达400多章的后宫文（bushi），但显然直接使用ai的话会导致一些无关紧要的上下文溢出，造成一些无关痛痒的失忆与幻觉。所以我想自己写一个ai小说生成

接下来就是寻找一个灵感

其实线索的灵感并非来源于别的文章生成，而是来源两个东西

一个是我电脑里的Stable Diffusion（稳定扩散），另一个就是烟云十六声

既然一本小说的大纲，主题，章节都是确定的，就好像一根绳子你只要固定住几个点即便剩下扩散的部分有些波动也不会影响整体的走势。接下来是燕云十六声，在观察剧情纵览时，我看到了两个词：明潮和暗涌。是的，我们只需要在大纲的基础上引入线索，就可以让ai写出完整的文章而不丢失记忆 *~~（真是个伟大的发现啊我到后来才找到别的小说生成器里也有类似的东西）~~*

接下来，又是参考了一些别人的ai长文生成，于是便有了这个玩意
